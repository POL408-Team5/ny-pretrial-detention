## ① Slide 1 Candidate Models and Baseline

- **Target**：`y_detain` = 1 表示提审时设保释或收押（Bail-set / Remanded），0 表示 ROR 或非金钱条件释放。**二分类**。
- **数据划分**：2021–22 训练，2023 验证（选模型），2024 测试（只用一次）。纽约市主样本 449,474 个案卷。
- **候选模型**：logit（L2）、LASSO logit（L1）、决策树、随机森林、XGBoost。基准是规则：指控等级 × 暴力重罪标记（2023 年 AUC 0.847）。
- **主指标 ROC-AUC**：正类只占约 12.8%，全部猜 0 的准确率也有 87%，所以不用 accuracy。我们关心的是把会被羁押的案件排在前面，这和阈值无关。补充报告 AP（适合不平衡数据）和 Brier（概率准不准）。

## ② Slide 2 Hyperparameter Tuning

- **方法**：在 2021–22 训练年上做 grid search，**5 折分层交叉验证**，按 ROC-AUC 选参数；预处理（缺失值填补、one-hot、标准化）放在 pipeline 里，每一折单独拟合。
- XGBoost 的树数用**早停**定：早停用的数据从每次训练数据内部切 20%，不用 2023 年。上限 2000 棵，50 轮没有改善就停。
- **参数表**（`CASE_COURT_JUDGE` 特征组；另外两组的最优值基本相同，个别不同的写在 notes 里）：

| 模型 | 搜索范围 | 最优 |
|---|---|---|
| Logit | C ∈ {0.01, 0.1, 1, 10} | C = 1 |
| LASSO | C ∈ {0.001, 0.01, 0.1, 1} | C = 1 |
| 决策树 | max_depth ∈ {3, 5, 8, 12} × min_samples_leaf ∈ {50, 200} | 12 / 200 |
| 随机森林（300 棵树） | max_depth ∈ {8, 16, None} × min_samples_leaf ∈ {20, 100} | None / 20 |
| XGBoost | max_depth ∈ {3, 5, 7} × learning_rate ∈ {0.05, 0.1}；subsample 0.8 | 7 / 0.05 |

- Notes 里写一句：logit、LASSO、决策树的最优值在搜索范围的边界上；没有再扩大，因为各模型之间的差距远大于调参带来的变化。

## ③ Slide 3 Model Comparison and Selection

- **比较表**（`CASE_COURT_JUDGE`）：交叉验证 AUC 用均值 ± 五折标准差；验证集 AUC 来自 2023 年。

| 模型 | 5 折 CV AUC（2021–22） | 2023 验证集 AUC |
|---|---|---|
| 规则基准 | — | 0.847 |
| Logit | 0.940 ± 0.002 | 0.924 |
| LASSO | 0.940 ± 0.002 | 0.924 |
| 决策树 | 0.936 ± 0.002 | 0.922 |
| 随机森林 | 0.940 ± 0.002 | 0.924 |
| **XGBoost** | **0.949 ± 0.002** | **0.935** |

- **选 XGBoost**：
  1. CV 和 2023 年都最高，三个特征组都是；比 logit 高 0.011（配对 bootstrap 95% 区间 [0.010, 0.012]）。
  2. 选模型看的是往后一年（2023）的表现，而不只看 CV。所有模型从 CV 到 2023 都下降了 0.013–0.016，XGBoost 没有额外的过拟合。
- 可选一句：logit 留作透明的参照模型。

## 11/19 补充：公平性（按 Week 8 Class 2 课件和老师反馈）

老师 11/19 的要求：模型的误差不能在群体之间不一致，否则实际中不可用；要做 disparity analysis 并**调整**，不只是报告。完整内容、数字和措辞规则见 `docs/公平性分析_按Week8课件修订_2026-11-19.md`。

对本 deck 的影响：
- ⑤ Slide 4 右侧的图建议换成**按种族的 Flag rate / TPR / FPR / Precision 条形图**（Black vs White，标注 n），两句解读：precision 和校准相等，FPR 不等（0.063 vs 0.040，ratio 0.64，不满足四分之四规则）；Black 组阈值提到 0.488 可使 FPR 相等，代价是该组 TPR 从 0.68 降到 0.58。
- 措辞：说 "unequal errors / disparity"，不说 "biased / unfair"；指控和前科是 signal，不是 bias；标签是历史决定，我们不评价决定本身。
- 答辩准备加两问：为什么选 FPR 作为要做平的比率（FP 的伤害落在被告身上，这是我们的政策选择）；分组阈值在实际中能不能用（有法律争议，我们只展示代价）。
