| 方面 | v1 | v2 | 原因 |
|---|---|---|---|
| 范围 | 全州，纽约市为主分析 | **只做纽约市五县**，全州不做 | 法院体系统一；结论限定在一个地区更扎实 |
| 划分 | 2021–22 训练 / 2023 验证 / 测试待定 | **2021–22 训练 / 2023 验证 / 2024 测试** | 跨年检验更干净；2024 需下载 |
| 子问题 | Q1、Q2、Q3 并列 | **Q1 + Q2 为主线**；Q3 和聚类等主结果跑通后再做 | 工作量；Q3 有样本选择和观察窗口问题 |
| 标签 | 设保释或收押 | 同上，但**名义保释（≤ $1）单独标记** | 读字典发现：$1 保释通常是因另一案已被收押、为折抵羁押天数而设，约占纽约市保释案件 20% |
| 样本 | 去当庭结案、Unknown | 另加：只保留地方法院 Docket 和 Felony Youth Complaint；同一逮捕周期去重 | 官方说明的数据完整性边界；避免同一逮捕事件重复计数 |
| 特征 | 地点组含辩护人类型 | **辩护人类型移出**（泄露） | 字典：记录的是“最近一次”律师类型，提审后请的私人律师也会显示 |
| 指标 | AUC 或 PR-AUC | AUC 为主，同时报告 AP、Brier、校准，测试集附 bootstrap 区间 | 反馈建议 |
| 列名 | 原始列名（含空格） | 读入时统一转成 `snake_case` | 方便所有人写代码 |

## 0. 一句话与决策设定

> 在纽约市，提审法官设保释或收押的决定，有多少能由案件和前科预测？加入法院和法官信息后能多预测多少？模型的误差在不同种族之间是否一致？

English (slides):
> How predictable are New York City judges' arraignment decisions to set bail or remand from the case and the defendant's record, how much do court and judge add, and are the model's errors similar across racial groups?

| 决策 | 决策者 | 时点 | 当时可见的信息 |
|---|---|---|---|
| 无条件释放 / 非金钱条件释放 / 设保释 / 收押 | 提审法官 | 被捕后约 24 小时内的提审 | 指控、前科、待决案件、监管状态、提审前是否未到庭、被告年龄性别、法院 |

**我们回答的是“历史司法决定的可预测性和差异”**，不能证明法官造成了差异，也不能证明存在歧视；不说“复现了实时部署”。

## 2. 数据

### 2.1 来源与文件

- NY State Unified Court System, Division of Technology & Court Research，**Pretrial Release Data**（州付费法院），公开 CSV，每个提审年一个文件。<https://www.nycourts.gov/division-technology-court-research/pretrial-release-data>
- 文件：`NYS for Web 2021.csv`、`2022.csv`、`2023.csv`（已下载，2026-11-06）；`2024.csv`（**待下载**）。三年列名完全一致，131 列。数据公开，以 gzip（`.csv.gz`，每个 23–31 MB）提交到仓库，全组共用同一版。
- 文档：数据字典 `docs/PretrialReleaseDataDictionaryWeb.xlsx`（2026-11-06 下载）；数据说明 `docs/Pretrial Release Data documentation- for website.pdf`。11/7 重新下载的字典与 11/6 版逐字节相同：官方字典**没有** “Nominal bail-set” 类别，也没有 DCJS 截止日期或 2024-11-19 之后的新字段的说明（此前反馈中的这几点无法从官方文件核实）；名义保释由保释金额识别。2024、2025 年文件与前几年列名和决定类别完全一致。

### 2.2 从官方说明核实过的要点（本地 PDF 和字典）

- **每半年更新一次**，旧案的后续信息（如处置）会在新版中补全 → 必须记录下载日期，全组用同一版文件。
- **一行 = 一个匿名“被告—案卷”**。同一被告的不同案卷无法关联；同一次逮捕的多个案卷可用 `arr_cycle_id` 关联，但只在匹配到 DCJS 记录时才有。
- 只收录**提审最高指控为重罪或轻罪**的案卷。
- 纽约市社区法院（Midtown、Red Hook）**2021-03-28 之后**才完整；上级法院在各自 `UCMSLiveDate` 之后才完整。
- **DCJS 字段缺失 = 没匹配到犯罪史记录，不等于没有前科**。
- 提审日期只有月和年。

### 2.3 2022 年纽约市的快速核查（未控制变量，只用于判断可行性）

去掉当庭结案和 Unknown 后 117,294 个案卷：

| 检查 | 结果 | 影响 |
|---|---|---|
| `arr_cycle_id` 缺失 | 3% | 缺失的行无法去重，保留 |
| 属于多案卷逮捕周期的行 | 11%；其中 13% 的周期内决定不一致 | 需要去重规则 |
| 案件类型 | Docket 91%，其余为上级法院类型 | 只留 Docket + Felony Youth Complaint [定] |
| 设保释中现金额 ≤ $1 | 20% | 名义保释单独处理 [定] |
| 设保释者从未交上 | 75%（去掉 ≤ $1 后 71%） | 补充页用后者 |
| 法官数 | 246 | 低频法官合并 |
| 检方请求字段 | 纽约市全部为空 | 不用 |

v1 中的全州数字（县间 24%–60%、AUC 0.87 等）来自全州样本，**deck 需要换成纽约市样本重算**。

## 4. 结果变量

| 变量 | 定义 | 用途 |
|---|---|---|
| `y_detain` | `Remanded` 或 `Bail-set` = 1；`ROR` 或 `Nonmonetary release` = 0 | **主标签**。名称是“是否设保释或直接收押”，**不叫“是否实际羁押”**（设保释的人可能交保） |
| `nominal_bail` | 设保释且首次保释金额都 ≤ $1 | 敏感性分析 |
| `bail_posted_at_arraign` | 设保释且提审当天交上 | 描述 |
| `released` | ROR、NMR，或设保释且提审当天交上 | Q3 样本 |
| `y_warrant` | 提审到处置之间签发逮捕令 | Q3 标签（观察窗口到处置为止，长短不一；未结案件要处理） |
| `y_rearrest` | 提审到处置之间再逮捕 | 只作补充；法律上不是保释的考虑因素 [核实] |

## 5. 特征（`src/features.py`）

### 5.1 三组嵌套特征 [定]

| 组 | 内容 | 回答的问题 |
|---|---|---|
| **CASE** | 指控等级、指控权重、暴力重罪标记、未遂、罪名类别、仇恨犯罪、逮捕类型、案件类型；三类前科数、三类待决、监管状态、前科是否缺失；提审前是否未到庭；年龄 | 案件和被告记录能预测到什么程度 |
| **CASE + COURT** | 再加县（纽约市每县一个 Criminal Court，只留 Docket 后法院名称与县一一对应） | 法院信息多预测多少 |
| **CASE + COURT + JUDGE** | 再加匿名法官编号 `judge_id` | 法官身份多预测多少 |
| 补充：CASE + 性别 | CASE 再加性别（11/7 暂定：性别和种族一样作为审计变量） | 在案件和记录之外，性别还能多解释多少；看结果后定最终做法 |

### 5.2 不进任何特征的变量

- **决定本身及之后才产生的**：释放决定、各类非金钱条件、保释金额与形式、交保信息、逮捕令、再逮捕、羁押天数、出庭次数、处置、判决。
- **辩护人类型**（`representation_type`）：字典定义为最近一次的律师类型，含提审后的信息；也是收入的代理变量。
- **检方请求**：纽约市为空，且部分字段只适用于 2024-11-19 之后。
- **种族、族裔、性别**：只用于公平性分组（性别另在补充特征组中单独比较）。
- **法官姓名**：只用匿名 `judge_id`，结果中不披露姓名。

### 5.3 预处理

类别变量 one-hot；前科缺失单独一列，不填 0；法官案件数少于 `MIN_JUDGE_CASES` 的合并为 `other`，验证 / 测试年新出现的法官记为 `unseen`；**所有填补、编码、调参只在训练数据内拟合**。

### 5.4 需核实

- 前科、待决案件是否按**提审时点**计算：UCS 字典和 DCJS 补充数据说明都没有写明（只有 `supervision` 写了 “at the time of arraignment”）。11/7 核查后列为局限（`data/README.md` D14）；可发邮件问 UCS DoTCR。

## 8. 不做的事与局限

**不做**：评价保释改革好坏；因果推断；给法官实名排名；预测“再犯”作主结果；全州分析。

**局限**：法官分配非随机（轮值），法官差异可能部分反映案件分配；被羁押者的到庭风险观察不到（Q3）；规则逐年修正，2024 年测试同时检验规则变化；没有证据强度、就业、住房等信息；前科缺失与种族未知（纽约市 2022 年约 1.6% 和 1.1%；v1 的 13% 和 16.5% 是全州数字）需检查缺失机制；数据每半年更新，结果对应某一版文件。
