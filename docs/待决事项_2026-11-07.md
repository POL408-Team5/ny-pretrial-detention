## 1. 性别要不要作为模型特征？

**为什么要决定**
- 种族和族裔已经定为**只用于公平性审计，不进模型**。性别目前在 `CASE` 特征组里，两者处理方式不一致，汇报时一定会被问。
- 性别在数据里差异很大。训练年主样本中，男性 15.8 万案、羁押率 14.8%；女性 3.5 万案、4.5%。只看重罪：男性 40.1%，女性 17.3%。这里面有一部分是指控结构不同造成的（男性的暴力重罪更多），另一部分可能是法官本身的差别对待。
- 法官在提审时确实能看到性别，所以它不算泄露。问题在于该不该让模型用它。

**选项**

| | A. 移出特征，只用于审计（与种族一致） | B. 保留在特征里 |
|---|---|---|
| 做法 | 把 `gender` 从 `FEATURES_CASE` 移到 `FAIRNESS_GROUPS` | 不改 |
| 能回答 | 只用案件和前科时，模型在男女之间的误差是否一致（和种族用同一套方法） | 性别对预测有多大作用（SHAP） |
| 代价 | 看不到性别的单独作用；如果法官确实区别对待，这部分差异会落进残差和分组误差里 | 要解释为什么性别能进模型、种族不能；如果模型学到了性别差异，等于把历史决定里的差别对待也学了进去 |
| 对 AUC | 可能略降（降幅有多少，冒烟测试时可以试一次） | 不变 |

**建议：A**。前后一致，也符合“模型只用案件和记录信息，受保护特征只做审计”的设计。可以在 SHAP 部分附一个补充：加入性别后，AUC 变了多少。

**决定（11/7，暂定）：** 主分析采用 A，性别移入审计变量（`config.FAIRNESS_GROUPS`）。同时新增补充特征组 `CASE_PLUS_GENDER`（= CASE + 性别），报告加入性别后 AUC 的变化，以及性别在 SHAP 里的排名。看完结果后再做最终决定。

## 2. 聚类和 Q3（未到庭）做不做？

**为什么要决定**
- 立项时我们自己承诺做五个模型、SHAP、聚类和公平性。大纲并不要求一定做聚类，但 11/11 那周课上正好讲 K-means 和层次聚类。
- Q3 要回答的是：被羁押的人是不是到庭风险更高的人？这和纽约保释法“只考虑到庭风险”的逻辑直接相关，是全项目最有政策意义的问题，但做起来难度最高：
  - **选择性标签**：被羁押的人观察不到是否到庭，所以只能在被释放的人里建模（训练年被释放者占 88.6%，其中 12.7% 后来被签发逮捕令）。
  - **观察窗口不一**：逮捕令统计的是从提审到结案这段时间，案件越晚结案，窗口越长。2023–24 年还有未结案件，标签不完整。
  - **工作量**：方案估计会多约 30%，而且集中在 11/16–19，和 deck 撞在一起。

**选项**

| | 聚类 | Q3 |
|---|---|---|
| A. 都不做 | 少一项课堂方法 | 少了最有政策意义的一环 |
| B. 聚类轻量做，Q3 冻结后再定（建议） | Yanqi 做一版：在 `CASE` 特征上分出几类典型案件，比较各类的羁押率和法官间差异（约半天） | 11/15 冻结后看进度：主线顺利就做一个简化版（只用 2021–22，只在被释放者里预测，和 Q1 的预测交叉看），不顺利就写进“下一步” |
| C. 都正式做 | 聚类单独成一页 | 需要在 11/10 前定好 Q3 的样本和窗口，Shuyi 的负担会更重 |

**建议：B。**

**决定（11/7）：** 采用 B。

## 3. 公平性分析用什么阈值把概率变成“预测羁押 / 释放”？

**为什么要决定**
- AUC 和校准不需要阈值，但 FPR（误判为羁押的比例）和 FNR（漏判的比例）需要先把概率切成 0/1。阈值不同，各组的 FPR/FNR 就不同，结论也会跟着变。
- 阈值必须在**验证年（2023）**定下来，测试年直接沿用，不能看了测试结果再调。2023 年的实际羁押率是 12.8%。

**选项**

| | 规则 | 优点 | 缺点 |
|---|---|---|---|
| A. 按实际比例（建议） | 在 2023 年选阈值，使预测为 1 的比例 = 实际羁押率 12.8% | 模型“羁押”的人数和现实一样多，误差比较直观；文献里常用 | 阈值随模型而变，每个模型各定一次 |
| B. 固定 0.5 | 概率 > 0.5 判为羁押 | 简单 | 正类只占 13%，0.5 会让预测为羁押的人很少，FNR 会很高，失去比较意义 |
| C. 按名额（top-k） | 风险最高的 k% 判为羁押，例如 10%、20% | 贴近“资源有限”的叙事 | k 不好解释，提审决定并没有名额限制 |
| D. 各组不同阈值 | 每个种族组各定一个阈值 | 可以让各组误差相等 | 等于按种族区别对待，和“种族不进模型”冲突，不建议 |

**建议：A**，并补充一张不依赖阈值的分组校准图。

**决定（11/7）：** 采用 A。
